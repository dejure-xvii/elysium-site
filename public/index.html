FAQ

Частые вопросы

Это безопасно?

Да. Код лаунчера и мода открыт на GitHub — его может проверить любой. Лаунчер скачивает игру только с официальных серверов Mojang и Fabric и проверяет файлы по контрольным суммам. Данные входа Microsoft хранятся в защищённом Диспетчере учётных данных Windows и никуда не отправляются. Предупреждение SmartScreen появляется лишь потому, что установщик не подписан платным сертификатом.

На каких серверах можно играть?

Мод клиентский, поэтому работает в одиночной игре и на любых серверах с версией 26.2. Большинство модулей — чисто визуальные. Некоторые вспомогательные функции (например, AutoSprint или ItemScroller) могут быть запрещены правилами отдельных серверов — перед игрой проверьте правила и отключите лишнее в ClickGUI.

Как обновлять?

Ничего делать не нужно. Мод обновляется автоматически при каждом запуске игры. Когда выходит новая версия лаунчера, он предложит обновиться — нажмите «Обновить» в настройках, и он перезапустится уже новым.

Какие системные требования?

Windows 10 или 11 (64-бит), 4 ГБ оперативной памяти и выше, около 1 ГБ свободного места. Java отдельно ставить не нужно — лаунчер скачает подходящую версию сам.

Нужна ли лицензия Minecraft?

Для входа через Microsoft нужна купленная Minecraft: Java Edition. Офлайн-аккаунт подходит для одиночной игры и серверов, которые его допускают.
